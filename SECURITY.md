# Security Policy

## Supported Versions

Security fixes are provided for the latest released version and the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities or suspected data leaks.

Report security issues through GitHub private vulnerability reporting if it is enabled for this
repository. If it is not enabled, contact the maintainers through the address listed in the GitHub
repository profile.

When reporting an issue, include:

- Affected version or commit.
- Operating system and Python version.
- Reproduction steps using dummy files only.
- Whether the issue can move, overwrite, delete, or expose local files.

## Privacy Model

PhotoTidy is designed as a local-only tool. It does not upload photos, videos, filenames, metadata,
or usage data. Please treat any future network access, telemetry, or crash reporting feature as a
security-sensitive change that requires explicit review and documentation before release.
